# Other PIQI Approaches

This folder will contain information related to other approaches for building, serializing, and otherwise processing PIQI model data.

The [quicktype](https://app.quicktype.io/) web site will generate boilerplate data classes (based on a JSON schema) in many different languages to allow a developer to get up and running quickly without having to focus on the tedious prcesss of hand coding the classes.

It's worth noting that the PIQI Alliance offers an [approach](https://github.com/piqiframework/transformationTemplates) of modeling and converting FHIR R4 data to the PIQI data model using liquid scripts.
